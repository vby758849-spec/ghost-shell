# ghost-shell
Hacker-style terminal launcher with Matrix rain wallpaper for Android.

## Build (phone se)
1. Is repo mein saari files upload karo (folder structure same rakho).
2. Actions tab -> "Build APK" -> run hone do.
3. Artifacts se `ghost-shell-apk` download karo, install karo.
4. Home dabao -> Ghost Shell -> Always.
5. Wallpaper: Settings -> Wallpaper -> Live wallpapers -> Matrix Rain.

## Commands
help, apps, open <name>, battery, time, whoami, hack, reset, lock, clear
